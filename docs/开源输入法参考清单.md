# 开源中文输入法项目参考清单

> 调研日期：2026-08-15。目的：为 CapsWriterIME 的拼音候选词引擎、智能预测功能提供代码参考索引。
> 按「候选词引擎参考价值」排序。星数/活跃度以调研当日为准。

## 第一梯队：候选词引擎核心（算法参考首选）

### 1. libime（Fcitx5 拼音引擎）⭐ 最推荐

| 项 | 值 |
|---|---|
| 仓库 | https://github.com/fcitx/libime |
| 语言 | C++（可 JNI 接入 Android） |
| 星数/活跃 | 54★，2026-08 仍在推送，非常活跃 |
| 双拼 | ✅ 内置（`shuangpinprofile.cpp`） |

**候选词引擎模块**（音节切分 + 按音节分组 + 智能预测全套）：
- `src/libime/pinyin/pinyindecoder.cpp` — Viterbi/Beam Search 解码器（核心算法）
- `src/libime/pinyin/pinyincontext.cpp` — 候选上下文管理、选词、预编辑；`update()` L672-840 是候选生成核心：位置倒序枚举 + 距离惩罚
- `src/libime/pinyin/pinyindictionary.cpp` — 拼音→词库 Trie 匹配（L594-688）
- `src/libime/pinyin/pinyinprediction.cpp` — 智能预测（L42-141，matchWordsPrefix 拆词法）
- `src/libime/pinyin/pinyinencoder.cpp` — 拼音音节编码/切分（L182-301，含双拼 parseUserShuangpin）
- `src/libime/pinyin/shuangpinprofile.cpp` — 双拼方案支持
- `src/libime/core/decoder.cpp` — Lattice 动态规划（buildLattice / forwardSearch / backwardSearch）
- `src/libime/core/historybigram.*` — 用户历史 bigram（选词学习）

> 原理：Trie 词库 + kenlm N-gram 语言模型 → SegmentGraph（音节切分图）→ Lattice（词典匹配网格）→ forward/backward beam search 得到 N-Best 候选。

### 2. AOSP PinyinIME（Google 拼音旧版开源）

| 项 | 值 |
|---|---|
| 官方仓库 | https://android.googlesource.com/platform/packages/inputmethods/PinyinIME/ |
| Android Studio 可编译 fork | https://github.com/lizhangqu/PinyinIME（218★） |
| 语言 | C++（jni）+ Java |
| 活跃 | 官方已停止开发（Android 5.1 后移除），fork 2026-08 活跃 |

**候选引擎模块**（`jni/share/matrixsearch.cpp`，C 风格，最直白易移植）：
- `prepare_candidates()` L1131-1189 — **按音节数逐级递减取词的核心**：`while (lma_size > 0) { get_lpis(..., lma_size); lma_size--; }`，先取最长音节整词再逐级递减到单字
- `get_lpis()` L1681-1778 — 取词/去重（多音节按字符串去重，单字按汉字去重）
- `inner_predict()` L1844-1946 — 智能预测：光标前 1~3 字做词典/用户词典前缀预测
- `search()` L419-478 — 输入入口，矩阵扩展

## 关键结论（对 CapsWriterIME）

1. **按音节数逐级递减**：抄 AOSP `prepare_candidates()` 的 `while (lma_size > 0) lma_size--` 模式——输入切分为 N 个音节后，从 N 字词逐级取到 1 字词。
2. **不显示超出拼音数量的词**：删掉当前 `phrasesByPrefix` 前缀联想（它会产生 nihaoa/nihaoma 超长词），只做「完整音节序列等长匹配」。
3. **智能预测**：抄 libime `matchWordsPrefix` 拆词法——已选词拼音作前缀，词典里找更长短语，截掉已选部分得预测词。
