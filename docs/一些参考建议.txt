==================================================
一、唯一双拼方案
==================================================

本项目只支持：

自然码双拼（Ziranma / Natural Code）

明确排除：

- 小鹤双拼
- 微软双拼
- 搜狗双拼
- 智能 ABC
- 拼音加加
- 其他所有双拼方案

不要实现多双拼方案切换。

不要为其他双拼方案预留复杂架构。

整个项目只围绕自然码双拼设计。

==================================================
二、首先分析现有项目
==================================================

开始开发前，先完整检查现有 Android 项目。

重点检查：

1. 项目目录结构
2. Gradle 配置
3. AndroidManifest.xml
4. InputMethodService
5. 输入事件处理
6. 当前拼音/双拼处理代码
7. 当前候选词处理
8. 当前候选栏
9. 当前文本提交逻辑
10. 当前数据存储
11. 当前设置页面
12. 当前用户配置
13. 当前 UI 与核心逻辑之间的接口

先判断：

- 哪些代码可以直接复用
- 哪些代码需要修改
- 哪些功能已经存在
- 哪些功能缺失
- 哪些地方存在性能问题

不要在没有检查现有代码之前自行重写。

==================================================
三、UI 修改原则
==================================================

UI 已经基本完成。

只有以下情况允许修改 UI：

1. 词库接入后候选栏必须增加候选词。
2. 当前 UI 无法显示必要的候选信息。
3. 存在明确 Bug。
4. 极少量交互调整。

除此之外：

不要修改布局。
不要重新设计键盘。
不要更换颜色方案。
不要重新设计候选栏。
不要重写主题。
不要改变用户已经可以正常使用的交互。

==================================================
七、统一词库结构
==================================================

统一转换成：

word
pinyin
ziranma
frequency
source
category

例如：

word = 人工智能
pinyin = ren gong zhi neng
ziranma = rf gs vi ng
frequency = 123456
source = rime-ice
category = common

只保存自然码。

不需要保存：

小鹤编码
微软编码
搜狗编码
其他双拼编码

==================================================
八、多音字
==================================================

必须按照“词”保存完整拼音。

例如：

银行
yin hang

行业
hang ye

行走
xing zou

不能只根据单字拼音生成。

==================================================
九、候选词系统
==================================================

用户输入自然码：

例如：

rfgsving

需要快速找到：

人工智能

同时支持：

- 完整匹配
- 前缀匹配
- 不完整输入
- 多音字
- 多音节词
- 长词
- 短语

候选词必须能够直接连接现有候选栏。

尽量保持现有 UI 接口不变。

如果现有 UI 已经有 Candidate 数据结构，优先适配现有结构，而不是重新设计。

==================================================
十、候选排序
==================================================

至少考虑：

base_frequency
user_frequency
recency
exact_match
context

建议使用：

log frequency
时间衰减
归一化
权重

不能简单：

frequency 越大越靠前。

最终目标：

用户越常输入的词越容易排到前面。

==================================================
十一、用户学习
==================================================

系统词库只读。

用户数据单独保存：

word
ziranma
use_count
last_used
created_at

用户选择候选词后：

use_count += 1
last_used = 当前时间

长期不使用需要衰减。

不能修改原始词库。
