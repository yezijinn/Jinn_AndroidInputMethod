## 8. 更重要：词库不要只存“词”

建议你的最终内部格式：

```text
词语
拼音
词频
来源
类别
权重
```

例如：

```text
虚拟    xu ni       98000    base       100
米雪儿  mi xue er    8000    game       80
某网络梗 xxx         5000    internet   60
角色名  xxx          3000    anime      50
```

这样你现在的 **`xuni → xun+i / xu+ni` 分词歧义问题**就可以直接利用词库解决：

```text
xuni

候选路径 A：
xun + i

候选路径 B：
xu + ni → 虚拟
```

如果 `虚拟` 是高频词：

```text
词频 + 完整词匹配 + 语言模型评分
```

就能让：

```text
xu + ni → 虚拟
```

明显优先于错误的：

```text
xun + i
```
