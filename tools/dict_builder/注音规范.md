# 中文词库注音规范

把无拼音的纯词表（如 THUOCL）转成输入法可用的拼音词库。生成时间：2026-09-15。

**输入** `词<TAB>词频` → **输出** `拼音<TAB>词1|词2|…`（同拼音的词合并一行）

## 一、六条硬规则

| # | 规则 | 正确 | 错误 |
|---|---|---|---|
| 1 | 无声调 | `beijing` | `běijīng` |
| 2 | 无空格连写 | `beijing` | `bei jing` |
| 3 | 全小写 | `beijing` | `BeiJing` |
| 4 | ü 写成 v | `nv`(女)、`lv`(绿) | `nü` |
| 5 | 能切成合法音节 | `bei` + `jing` | 任意字母串 |
| 6 | 每字都注音 | `zhongguo` | `zhongg` |

规则 5 最容易错：引擎会把键切成合法音节序列再查询，**切不开的键永远查不到**，等于废条目。
合法音节共 422 个（见 `app/src/main/assets/pinyin_syllables.txt`）。三条事实：
单字母合法音节只有 `a e m n o`（不存在 `y`/`w` 单独成音节）；不存在 v 开头的音节；
`yyds`、`CS2`、`DOTA2` 这类字母数字组合不能做键 —— 收集网络词 / 游戏词时必须剔除含字母或数字的条目。

## 二、注音数据源（按优先级）

1. **查现成词库**（最准）：`docs/rime-ice/cn_dicts/{base,ext,tencent}.dict.yaml`，
   格式 `词<TAB>拼音(空格分隔)<TAB>词频`（tencent 格式略不同，需单独解析）。查到就直接用其拼音（去空格）
2. **逐字查字表**：`docs/rime-ice/cn_dicts/8105.dict.yaml`（8,182 字，同格式；一个字可能多行 = 多音字）
3. **兜底**：多音字无法确定读音 → **丢弃该词，不要猜**（注错拼音的词是废条目，用户打不出来还占体积）

## 三、多音字

原则：一个词有几种正确读音，就生成几条（多条键指向同一个词）。由词组本身决定读音的必须注对，不能逐字瞎拼。

| 词 | 正确 | 常见错误 |
|---|---|---|
| 重庆 / 银行 / 音乐 | `chongqing` / `yinhang` / `yinyue` | ~~zhongqing~~ / ~~yinxing~~ / ~~yinle~~ |
| 长大 / 便宜 / 参差 / 单于 | `zhangda` / `pianyi` / `cenci` / `chanyu` | ~~changda~~ / ~~bianyi~~ / ~~cancha~~ / ~~danyu~~ |

## 四、输出格式

`拼音<TAB>词1|词2|…`：拼音与词之间用 TAB；同拼音的词用 `|` 合并一行并按词频降序；
UTF-8 纯文本，无表头、无注释、无空行。

## 五、交付前自检

| 检查 | 通过标准 |
|---|---|
| 键能被合法音节切分 | **失败数 = 0** |
| 词是纯中文（`^[\u4e00-\u9fff·]+$`） | 无字母 / 数字 / 标点（间隔号 · 合法） |
| 无空键、空词 | 无 |
| 同键无重复词 | 无 |
| 抽查 20 个高频词 | 注音全部正确 |

切分校验（与引擎逻辑等价）：

```python
valid = set(open('pinyin_syllables.txt', encoding='utf-8').read().split())
maxlen = max(len(s) for s in valid)

def can_segment(key):
    n = len(key)
    reach = [False] * (n + 1)
    reach[0] = True
    for i in range(n):
        if not reach[i]:
            continue
        for L in range(1, maxlen + 1):
            if i + L <= n and key[i:i + L] in valid:
                reach[i + L] = True
    return reach[n]
```

## 六、交给助手工具的任务指令（复制即用）

```
把一份中文纯词表注音，转成输入法拼音词库。
输入：每行 `词<TAB>词频`。
输出：每行 `拼音<TAB>词1|词2|…` —— TAB 分隔，同拼音的词合并一行并按词频降序，无表头、无注释、无空行。

规则（六条）：无声调、无空格连写、全小写、ü 写成 v、键必须能切成合法音节（共 422 个，单字母只
a/e/m/n/o，不存在 v 开头音节）、词中每字都注音。

数据源：先查 docs/rime-ice/cn_dicts/{base,ext,tencent}.dict.yaml（格式 `词<TAB>拼音<TAB>词频`，查到
就用其拼音并去空格）；查不到再逐字查 8105.dict.yaml；多音字无法确定读音就丢弃，不要猜。

多音字必须注对：重庆=chongqing、银行=yinhang、音乐=yinyue、长大=zhangda、便宜=pianyi、参差=cenci。

剔除：含字母或数字的词（CS2、DOTA2）、含标点的词、超 8 字的句子；保留间隔号 ·（如 奥黛丽·格罗夫）。

自检：全部键可切分（失败数 0）、全部词匹配 ^[\u4e00-\u9fff·]+$、同键无重复词、抽查 20 个高频词全对。
最后报告：总词条数、有效键数、因无法注音而丢弃的条目数及样例。
```

## 七、参考：本项目词库形态

基础包（内置 APK）词长 ≤4 字；扩展包（按需下载）>4 字；单字表 `pinyin_chars.txt` 用**逗号**分隔
（与词库的 `|` 不同）；两个词库都用 xz 压缩，参数 `preset=7, lc=4, pb=0`。
