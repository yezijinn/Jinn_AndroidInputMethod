# 中文词库注音规范（交给 AI 执行用）

> 目标：把**无拼音的纯词表**（如 THUOCL）转换成输入法可用的**拼音词库**。
> 生成时间：2026-09-15

---

## 一、任务概览

**输入**：纯词表，每行 `词<TAB>词频`（THUOCL 格式）
```
文件备份	1234
虚拟地址	987
事务调度	456
```

**输出**：拼音词库，每行 `拼音<TAB>词1|词2|词3...`
```
wenjianbeifen	文件备份
xunidizhi	虚拟地址
shiwudiaodu	事务调度
```

给每个词标出**正确的拼音键**，并把同拼音的词合并到一行。

---

## 二、拼音的六条硬规则

| # | 规则 | 正确 | 错误 |
|---|---|---|---|
| 1 | **无声调** | `beijing` | `běijīng` |
| 2 | **无空格、连写** | `beijing` | `bei jing` |
| 3 | **全小写** | `beijing` | `BeiJing` |
| 4 | **ü 写成 v** | `nv`(女)、`lv`(绿) | `nü`、`nǚ` |
| 5 | **必须能切成合法音节** | `bei` + `jing` | 任意字母串 |
| 6 | **词中每字都要注音，不省略** | `zhongguo` | `zhongg` |

### 规则 5 是硬约束（最容易出错的一条）

引擎会把键**切分成合法音节序列**再查询，**切不开的键永远查不到**，等于废条目。

**合法音节表共 422 个**，完整清单见项目里的 `app/src/main/assets/pinyin_syllables.txt`，
开头是：

```
a  ai  an  ang  ao  ba  bai  ban  bang  bao  bei  ben  beng  bi  bian  biang  biao  bie  bin  bing  bo  bu  ...
```

**三条必须记住的事实**：

1. **单字母合法音节只有 `a` `e` `m` `n` `o`** —— 不存在 `y`/`w` 单独成音节
2. **不存在 v 开头的音节**（v 只出现在 `nv` `lv` `nve` `lve` 这类韵母位）
3. 所以 **`yyds`、`CS2`、`DOTA2` 这类字母数字组合不能做键**（切不开）
   —— 收集网络词/游戏词时**必须剔除**含字母或数字的条目

---

## 三、注音数据源（按优先级使用）

### ① 首选：查现成词库（最准）

项目里已有 rime-ice 词库，**格式为 `词<TAB>拼音(空格分隔)<TAB>词频`**：

```
docs/rime-ice/cn_dicts/base.dict.yaml      542,853 条（100% 带词频）
docs/rime-ice/cn_dicts/ext.dict.yaml       339,327 条
docs/rime-ice/cn_dicts/tencent.dict.yaml   981,967 条（格式略不同，需单独解析）
```

**用法**：待注音的每个词，先去这三份里查。**查到就直接用它的拼音**（把空格去掉）。
这三份是人工校对过的，比任何自动注音都可靠。

### ② 次选：逐字查字表

查不到的，用**字→拼音**映射逐字注音。字表同样来自 rime-ice：

```
docs/rime-ice/cn_dicts/8105.dict.yaml    8,182 字
```

格式同样是 `字<TAB>拼音(空格分隔)<TAB>词频`，例：
```
啊	a	1234
阿	a e	987
```

**注意**：一个字**可能有多行**（多音字），每行是一个读音。

### ③ 兜底：多音字无法确定时

**丢弃该词，不要猜。** 注错拼音的词是废条目——用户打不出来，还占体积。

---

## 四、多音字处理

**原则：一个词有几种读音，就生成几条（多条键指向同一个词）。**

例：「重庆」只有 `chongqing` 一种正确读音，**不要**生成 `zhongqing`。
但「银行」是 `yinhang`、「行走」是 `xingzou`——这类**由词组本身决定读音**的，
必须注对，不能逐字瞎拼。

**判断顺序**：
1. 词在 rime-ice 词库里 → **用词库的读音**（它已处理好多音字）✓
2. 词不在词库里 → 逐字注音，但**若某字是多音字且词义无法判断读音 → 丢弃**

**典型易错词**（必须注对）：
| 词 | 正确 | 常见错误 |
|---|---|---|
| 重庆 | `chongqing` | ~~zhongqing~~ |
| 银行 | `yinhang` | ~~yinxing~~ |
| 音乐 | `yinyue` | ~~yinle~~ |
| 长大 | `zhangda` | ~~changda~~ |
| 便宜 | `pianyi` | ~~bianyi~~ |
| 参差 | `cenci` | ~~cancha~~ |
| 单于 | `chanyu` | ~~danyu~~ |

## 五、输出格式（严格）

```
拼音<TAB>词1|词2|词3...
```

- 拼音与词之间用 **TAB**（不是空格）
- 同拼音的多个词用 **`|`** 合并到一行
- **同键内按常用度/词频降序**（有词频就按词频排）
- 纯文本 UTF-8，**无表头、无注释、无空行**

**示例**：
```
beijing	北京
wenjianbeifen	文件备份|文件备份库
xunidizhi	虚拟地址
```

## 六、交付前的自检清单

把结果跑一遍这些检查，**任一项不通过就要修**：

| 检查 | 方法 | 通过标准 |
|---|---|---|
| **① 键能否切分** | 用合法音节表做切分（见下伪代码） | **失败数 = 0** |
| **② 词是否纯中文** | 正则 `^[\u4e00-\u9fff·]+$` | 无字母/数字/标点 |
| **③ 是否有空键或空词** | 逐行检查 | 无 |
| **④ 同键是否有重复词** | 同键内 set 去重 | 无重复 |
| **⑤ 抽查常用词** | 手工抽 20 个高频词 | 全部注音正确 |

**切分校验的伪代码**（与输入法引擎逻辑等价）：

```python
valid = set(open('pinyin_syllables.txt', encoding='utf-8').read().split())
maxlen = max(len(s) for s in valid)

def can_segment(key):
    n = len(key)
    reach = [False] * (n + 1)
    reach[0] = True
    for i in range(n):
        if not reach[i]: continue
        for L in range(1, maxlen + 1):
            if i + L <= n and key[i:i+L] in valid:
                reach[i + L] = True
    return reach[n]
```

## 七、可直接使用的提示词

```
# 任务
把一份中文纯词表注音，转换成输入法拼音词库。

# 输入
文件格式：每行 `词<TAB>词频`

# 输出（严格）
每行 `拼音<TAB>词1|词2|词3...`
- 拼音与词之间用 TAB
- 同拼音的词用 | 合并到一行，按词频降序
- 无表头、无注释、无空行

# 拼音规则（六条，必须全部遵守）
1. 无声调（beijing，不是 běijīng）
2. 无空格连写（beijing，不是 bei jing）
3. 全小写
4. ü 写成 v（nv=女、lv=绿）
5. 必须能切分成合法音节（表见 pinyin_syllables.txt，422 个）
   —— 单字母合法音节只有 a/e/m/n/o，不存在 y/w 单独成音节；
      不存在 v 开头的音节
6. 词的每个字都要注音，不省略

# 注音数据源（按优先级）
1. 先查 docs/rime-ice/cn_dicts/{base,ext,tencent}.dict.yaml
   —— 格式 `词<TAB>拼音(空格分隔)<TAB>词频`，查到就用它的拼音（去空格）
2. 查不到则逐字查 docs/rime-ice/cn_dicts/8105.dict.yaml（字→拼音）
3. 多音字且无法确定读音 —— 丢弃该词，不要猜

# 多音字要求
- 词有多个正确读音时，生成多条（多条键指向同一个词）
- 由词组决定读音的必须注对：重庆=chongqing、银行=yinhang、
  音乐=yinyue、长大=zhangda、便宜=pianyi、参差=cenci
- 绝不逐字瞎拼多音字

# 必须剔除的条目
- 含字母或数字的词（如 CS2、DOTA2、刀塔2）—— 引擎切不开，是废条目
- 含标点的词（括号、逗号、斜杠等）
- 超长词（>8 字，多半是句子）
- 保留间隔号 ·（中文译名用，如 奥黛丽·格罗夫 是合法的）

# 交付前自检
1. 全部键能被合法音节切分，失败数必须为 0
2. 全部词匹配 ^[\u4e00-\u9fff·]+$
3. 同键内无重复词
4. 手工抽查 20 个高频词，注音全部正确
最后报告：总词条数、有效键数、因无法注音而丢弃的条目数及其样例。
```

## 八、参考：本项目词库的最终形态

- **基础包**（内置 APK）：词长 ≤4 字
- **扩展包**（按需下载）：词长 >4 字
- **单字表**：单独的 `pinyin_chars.txt`，格式 `拼音<TAB>字1,字2,...`（**逗号分隔**，与词库的 `|` 不同）
- 两个词库文件都用 **xz** 压缩，参数 `preset=7, lc=4, pb=0`（兼顾体积与解压内存）
