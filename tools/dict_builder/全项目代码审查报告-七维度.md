## 三、P3 加固建议（唯一发现）

### 命令拼接未加引号

**位置**：`ClipboardFirewall.kt:102 / 109 / 115 / 127`

```kotlin
val out = su("ls -ld $dataDir") ?: return "数据目录权限" to "无法访问（su 失败）"
val out = su("ls -l $dbPath")   ?: return ...
val out = su("stat -c '%U' $dataDir") ?: return ...
val out = su("find $dataDir -type l 2>/dev/null") ?: return ...
```

**原因**：路径变量直接拼进 shell 命令且**未加引号**。当前**不可利用** ——
`dataDir` 取自 `context.dataDir.absolutePath`，恒为 `/data/user/0/<包名>` 形式，
系统保证不含空格与特殊字符。但这是**依赖外部前提的安全性**：
若 Android 将来改变数据目录路径规则，或代码被改为接受外部传入的路径，
就会退化为命令注入。

**修复建议**：给路径加单引号，使其不依赖"路径恰好安全"这一前提。

**优先级说明**：P3 —— 当前无实际风险，属防御性加固。
本次已一并实施（见提交记录）。
