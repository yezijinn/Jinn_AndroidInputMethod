# 「连写歧义」类漏词补丁
#
# 格式：词<TAB>拼音（空格分隔）<TAB>插入位置(1-based，可选)
#
# 为什么是这些词：拼音连写会吞掉音节边界。当词的拼音 S1 + Z
# （Z 为零声母音节 a/ai/an/ang/ao/e/ei/en/eng/er/o/ou）连写后恰好等于
# 另一个合法单音节时，该词就与那个单音节同键：
#     企鹅(qi e) → qie 与「切」同键
#     西安(xi an) → xian 与「先」同键
# 源词表漏收这类词时，用户输入 qie（双拼 qiee）只能看到「切/且/窃」，
# 永远打不出「企鹅」。
#
# 插入位置选 4：落在最常用的三个单字之后，既不抢走第一候选，
# 也不用翻到几十个候选的末尾才找得到。
#
# 排查工具：tools/dict_builder/detect_ambiguous_keys.py
